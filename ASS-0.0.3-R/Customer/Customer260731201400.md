# ความคืบหน้าปัจจุบัน

* ได้ดำเนินการดาวน์โหลด จัดเตรียม และสร้าง (Build) Runtime Library
ที่ใช้สำหรับการประมวลผลและวิเคราะห์ข้อมูลเสียงเรียบร้อยแล้ว ประกอบด้วย

- FFmpeg

- Eigen
- AudioFlux
- Basics
- dr_libs
- DSP
- nlohmann/json
- KissFFT
- libebur128
- LibXtract
- miniaudio
- ONNX Runtime
- PFFFT
- Signalsmith Stretch
- TinyXML2

# สถานะการดำเนินงาน
- ได้จัดเตรียม Runtime Library สำหรับใช้งานภายในระบบเรียบร้อยแล้ว.
- ได้แยกและจัดการ Runtime ของแต่ละ Library เพื่อรองรับการพัฒนาและการบำรุงรักษาในอนาคต0.
- อยู่ระหว่างดำเนินการเชื่อมต่อ Library เข้ากับระบบวิเคราะห์ข้อมูลเสียง (Audio Analysis Pipeline).
- อยู่ระหว่างการทดสอบการทำงานร่วมกันของแต่ละโมดูล เพื่อให้ระบบมีความเสถียรและพร้อมใช้งาน.

# ขั้นตอนถัดไป
- เชื่อมต่อ Runtime เข้ากับระบบวิเคราะห์ทั้งหมด.
- พัฒนากระบวนการวิเคราะห์ข้อมูลเสียงและ Metadata.
- พัฒนาระบบเปลี่ยนชื่อไฟล์ตามรูปแบบที่กำหนด.
- ทดสอบการทำงานแบบครบทุกขั้นตอน (End-to-End Testing).
